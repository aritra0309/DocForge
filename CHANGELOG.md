# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-08-03

### Added

- Documentation discovery, crawling, extraction, classification, chunking, embedding, and vector storage pipeline.
- CLI and Python APIs for indexing, searching, updating, re-embedding, inspection, and deletion.
- Built-in registries for PostgreSQL, MySQL, MongoDB, FastAPI, React, Kubernetes, and Redis.
- Pluggable chunking, embedding, and vector-store interfaces.
- MkDocs documentation site, examples, CI, documentation deployment, and PyPI release workflows.
